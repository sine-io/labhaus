# 用户故事地图

**项目**：Labhaus
**当前阶段**：图像素材 MVP -> 视频工作流
**最后更新**：2026-07-08

---

## 用户角色

### 内容创作者

- 希望快速验证不同视觉风格。
- 希望把一次成功的创意扩展成多张素材，后续扩展为多条视频。

### 营销和内容团队

- 希望围绕活动、产品或文案批量生产素材。
- 希望团队能复用样式和工作流，减少重复调参。

### 开发者/自动化团队

- 希望通过 API 或自部署方式接入内容生成能力。
- 希望 Provider、存储、队列和工作流可替换、可扩展。

## 当前 MVP 用户旅程

### 1. 注册和登录

- [x] 用户可以用邮箱、密码、名称注册。
- [x] 用户可以登录并获得 Bearer Token。
- [x] Web 前端可以保存和清除 Token。

验收标准：

- 注册成功返回用户信息。
- 登录成功返回 `{ token, user }`。
- 受保护接口未带 Token 时返回 401。

### 2. 获取样式方向

- [x] 用户可以调用样式列表接口查看当前 seed 样式。
- [x] 用户可以输入创意描述获得推荐样式。
- [x] 推荐结果包含 name、description、prompt、category、tags、score。

验收标准：

- `/api/styles/recommend` 接受 `{ query, limit }`。
- 默认 limit 为 10。
- 当前运行时按关键词重叠打分；后续接入 TF-IDF + Cosine。

### 3. 批量生成图像素材

- [x] 用户可以输入多条 prompt。
- [x] 用户可以配置 width、height、quality 和可选 style。
- [x] 后端并发调用图像 Provider。
- [x] 生成结果上传 MinIO。
- [x] 用户获得可打开或下载的预签名 URL。

验收标准：

- `/api/images/generate` 返回 `results`、`total`、`success`、`failed`。
- Next.js 代理兼容暴露 `images` alias 给前端页面。
- 本地 mock provider 能完成端到端演示。

## 下一阶段：视频工作流用户旅程

### 4. 从文本生成视频

- [ ] 用户输入文章 URL 或正文。
- [ ] 系统生成结构化脚本。
- [ ] 系统拆分分镜。
- [ ] 系统为分镜推荐或应用样式。
- [ ] 系统批量生成分镜图。
- [ ] 系统生成配音和字幕。
- [ ] 系统用 FFmpeg 合成 MP4。

验收标准：

- 用户能从文本得到可预览 MP4。
- 每个中间产物可查看。
- 失败时能定位具体步骤。

### 5. 任务监控

- [ ] 用户可以查看任务列表。
- [ ] 用户可以查看任务详情、状态和错误。
- [ ] 用户可以预览中间图片、音频和最终视频。
- [ ] 用户可以重试失败步骤。

### 6. 可视化工作流

- [ ] 用户可以拖拽输入、LLM、生图、TTS、视频合成、输出节点。
- [ ] 用户可以保存和加载工作流。
- [ ] 用户可以复用成功配置。

### 7. 模板和团队

- [ ] 用户可以保存工作流为模板。
- [ ] 团队可以共享模板和样式。
- [ ] 后续支持配额、计费、权限和私有部署。

## 优先级

### P0：当前 MVP

1. 注册/登录。
2. 样式推荐。
3. 批量生图。
4. MinIO 下载链接。
5. 本地 demo smoke。

### P1：视频工作流闭环

1. 文本/文章输入。
2. 剧本和分镜。
3. 分镜图批量生成。
4. TTS 和字幕。
5. FFmpeg 合成。
6. 任务状态。

### P2：可视化和复用

1. React Flow 编辑器。
2. 工作流保存。
3. 模板复用。

### P3：商业化和协作

1. 团队协作。
2. 配额和计费。
3. 模板市场。

## 成功指标

当前 MVP：

- 用户能在 10 分钟内完成“登录 -> 推荐 -> 批量生图”。
- 生成结果可打开或下载。
- 本地 smoke 脚本稳定通过。

视频阶段：

- 用户能从一段文本得到可用视频。
- 中间产物可追踪、可重试。
- 成功工作流可复用。
