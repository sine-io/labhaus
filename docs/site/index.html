样式推荐

登录后输入创意描述，系统基于当前样式库返回匹配的视觉方向。当前运行时使用关键词重叠打分，后续接入 TF-IDF + Cosine 推荐。

🖼️

批量生图

一次提交多条 prompt，后端并发调用图像 Provider，下载结果并上传 MinIO，返回可打开和下载的预签名链接。

🎬

下一阶段把当前图像素材能力扩展为文本/文章到分镜、生图、配音、字幕和 FFmpeg 合成的完整视频流程。
